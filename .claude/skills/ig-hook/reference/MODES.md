# Hook modes

Choose a dominant visual mode from the claim and available evidence. Do not begin from a
favorite effect. The mode determines what the viewer sees at frame zero and what must change
by second five.

## Selection order

Use the first mode whose requirements are honestly satisfied:

1. A real surprising result exists → **RECEIPT-FIRST**.
2. Two real outcomes or methods can be compared → **COMPARISON-FIRST**.
3. The problem or correction can be performed physically → **DEMONSTRATION-FIRST**.
4. The objection can be acted as a scene → **ROLEPLAY-FIRST**.
5. The value lives inside an app or workflow → **INTERFACE-DIVE**.
6. Repetition or visual sameness is the claim → **PATTERN-BREAK**.
7. The thesis is strong but none of the above can be shown → **LOCKUP-FIRST**.

Lockup is a fallback, not the universal shape of a visual hook.

## RECEIPT-FIRST

**Frame zero:** the actual analytics, dashboard, document, calendar, or result.  
**Best for:** “4M views, $0,” follower/reach gaps, saves, revenue, time saved.  
**Second beat:** identify the contradiction inside the receipt.  
**Owner:** usually both—Premiere supplies the person and timing; HyperFrames rebuilds or
annotates the evidence.  
**Failure:** talking about the number while showing only a large text version of it.

## COMPARISON-FIRST

**Frame zero:** both real sides, simultaneously legible.  
**Best for:** winning/losing hooks, before/after, settings, edits, distribution tests.  
**Second beat:** mark the one meaningful difference or explicitly reveal that no creative
difference exists.  
**Owner:** HyperFrames for layout/annotation; Premiere when the sides are moving clips.  
**Failure:** unrelated metrics, mismatched windows, or duplicated imagery pretending to be
different evidence.

### The sameness-is-the-claim carve-out

Identical assets are allowed only when **verified sameness is the evidence**—for example,
the byte-identical Reel that received 1,469 views in one distribution context and 294 in
another. Set `comparison.samenessIsClaim: true`, cite the provenance in the Hook Packet,
and make the sameness explicit on screen. Otherwise duplicate assets remain banned.

## DEMONSTRATION-FIRST

**Frame zero:** the mistake and consequence are already visible.  
**Best for:** white captions over a white shirt, back versus front camera, bad framing,
settings, profile fixes.  
**Second beat:** perform the correction; do not postpone the answer.  
**Owner:** Premiere first. HyperFrames may annotate the consequence.  
**Failure:** replacing a physical demonstration with a diagram or a list.

## ROLEPLAY-FIRST

**Frame zero:** begin inside the conflict—question, complaint, or objection.  
**Best for:** export settings, coach/client misunderstandings, creator excuses, sales DMs.  
**Second beat:** the other character contradicts the obvious explanation.  
**Owner:** Premiere. HyperFrames supports with settings, messages, or proof.  
**Failure:** introducing the characters or explaining the scenario before it starts.

## INTERFACE-DIVE

**Frame zero:** the real UI is already performing the consequential action.  
**Best for:** ContentSpy, Claude workflows, analytics, profile audits, DMs, automations.  
**Second beat:** zoom or annotate the exact field responsible for the result.  
**Owner:** HyperFrames for faithful reconstruction; Premiere for real screen recordings.  
**Failure:** a generic dashboard mockup, fake app chrome, or invented data.

## PATTERN-BREAK

**Frame zero:** a wall or repeated field establishes sameness; one physical event breaks it.  
**Best for:** “your set became wallpaper,” everyone uses the same hook, generic gurus,
content sameness.  
**Second beat:** isolate the outlier and explain the mechanism of difference.  
**Owner:** both.  
**Failure:** random spectacle with no relationship to the claim.

## LOCKUP-FIRST

**Frame zero:** 3–7 word summary, power word, and one wide proof object.  
**Best for:** abstract thesis, warning, or named method when stronger literal evidence does
not exist.  
**Second beat:** the proof object resolves or the edit cuts to literal evidence.  
**Owner:** HyperFrames.  
**Build spec:** `ig-show/reference/VISUAL-HOOK.md`.  
**Failure:** treating the lockup as mandatory when a demonstration, receipt, or scene exists.

## Mode diversity in the lab

A useful three-candidate set changes the visual grammar, not just the line:

- A: receipt or comparison;
- B: demonstration, role-play, or interface action;
- C: pattern-break or lockup.

Keep the underlying promise and post-second-eight body constant. If candidate B teaches a
different lesson, it is a different concept—not a hook test.
