# multiply
One of the creator's REAL tiles sits alone and breathes; a ring lights it (`reveal_at[0]`, "the right
setup"); then it bursts into `count` copies laid in a grid while the number counts up with them
(`reveal_at[1]`, on the spoken number). A spoken multiple — "30 times", "10× the output" — shown as
thirty things instead of a digit. Every copy is a unit of quantity, never a fake different item, so the
same image is the honest choice. Needs the spoken number with `source` (provenance is enforced).
Wrong for an absolute figure (use `metric`) or for anything not said by the speaker.
