# drag-drop
"I drop it into X", "upload it to Y", "send it to Z" — the action, performed: a cursor grabs the real file
(a frame of it + its real filename), drags it in an arc into a window named for the real app, and on release the
drop zone floods azure, a ring goes out, the progress bar fills and a check lands. Everything named is real.
Placement: `top` (default, above the head) or `inline`.
