# agent-chat

"X just dropped an AI agent / tell it to do Y / it'll analyze Z" — the agent shown as what it is: a chat on a phone,
played along the line instead of described. The phone sits low in the frame from frame zero and slams up on the
drop word; the agent's name is a skeleton until the speaker names it, then types in; the speaker's own prompt types
into the composer across the words they say it with and sends; the header status flips on the words that name what
the agent is doing; replies arrive in one slot and replace each other: typing dots, an app connection (pill checks on
the app's name), the creator's REAL tiles scanned one by one with a hero picked, or follower rows (skeletons, no
invented names) that get a chip each.

Placement: `inline` only — the phone fills the bottom of the frame below the caption band (y 1160 → off-screen), the
face stays clear. One long graphic is fine: the object persists and something happens every 1–2 s (set `reveal_at`
to every internal event so pacing and SFX see them; `sfx_events` in the plan picks a verb per event).

Real only: the avatar is cropped from the product's own screenshots; prompts and statuses are the speaker's words;
tiles are the creator's posts; never an invented reply, result or number.
