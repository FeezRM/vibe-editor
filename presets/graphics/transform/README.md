# transform
"I take X and run it through Y", "it turns my idea into a script" — a process shown as a machine, not a flow
chart. The input (an icon from `_icons.html` or a real image) drops in and lights up on its word, arcs into the
machine's intake, the machine shakes, its gear races and a scanline runs, and the output slides out of the far
side and writes itself. The label is the speaker's own noun or the real tool name. Use `flow` when the steps
are the point and `transform` when the *change* is. Placement: `inline` (default) or `top`.
