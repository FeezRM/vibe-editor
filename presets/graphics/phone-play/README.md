# phone-play
"the video you're watching right now", "this reel", "you're looking at it" — recursion. A phone rises from the
bottom edge with the reel itself playing inside it at the same moment (cut the spine for exactly this graphic's
window), a double-tap heart pops, a pulse rings the phone. The only preset with live video; it needs the job's
own spine, never someone else's footage. Placement: `inline` only (the phone runs off the bottom edge).
