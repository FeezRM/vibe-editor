# upgrade
"30 times better", "10× sharper" — *better* is quality, not quantity, so the one thing stays one thing
and improves: it arrives grey, soft and small; a dial of `count` ticks fills around it while the number
climbs 1→N; the picture sharpens, colours in and gets its glow; the spoken quality `word` lands.
Use `multiply` for MORE (30 things), `upgrade` for BETTER (one thing, 30×). Needs the creator's own
tile and the spoken number with `source`. Wrong for a number that isn't a multiple of quality.
