# scan
A single row of the creator's REAL tiles (reels, posts, thumbnails) that does one of two things: in `dim`
mode they die one by one, left to right — the threat ("your content if you don't…"); in `scan` mode one
bright line sweeps the row and every tile gets boxed and checked as it passes — a machine reading the
whole grid in under a second — and at `reveal_at[1]` the `hero` tile wins while the rest grey out.
Use the same tiles in both modes across a video: the object returns and advances (S1/S3 device).
Needs: 2–8 real images with provenance. Wrong for images that are not the creator's own or captured.
