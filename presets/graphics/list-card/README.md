# list-card
A titled card whose rows appear one per cue with a ✓ / ✕ / number mark. Use it when the speaker lists
things (three problems, four steps, what's included). Rows must be the spoken items, in the spoken
order, revealed on the word that names them. Wrong when there is only one item (use `phrase`) or when
the items are things you can show (use `thumb-wall` / `receipt`).
