# agent-run
"The AI setup", "my system", "the agent does it" — a *setup* is a machine working, not a product page.
This is a console card: the real session title in the bar, 2–5 real task lines that type themselves,
spin, and check off one per beat, then a result pill with what the run actually produced. Every
string is real: the session name, the steps the run took (read them off the real transcript or
artifact header), the artifact it made. Wrong when nothing was actually run — then there is no setup
to show, and inventing steps is fabrication.
