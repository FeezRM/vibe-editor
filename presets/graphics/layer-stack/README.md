# layer-stack
"it makes the captions, the motion graphics, everything" — an edit shown as what it is: layers. Three cards fan
out in 3D — the real footage frame, a glass captions layer carrying the real caption (from `captions.json`, same
face and accent as the real captions), a glass graphics layer carrying a real still of one of the reel's own
graphics — each landing on its word; on "everything" they slam together into one flat frame with a flash.
Placement: `top` (default) or `inline`.
