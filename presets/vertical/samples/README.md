# vertical/samples

The mechanical look measured from the reference reels in `samples/` — captions, accent colours, loudness. What to put
on screen and when is in `samples/STYLE.md`. Re-measure with `ig-study` when the samples change.

The sample captions use a geometric bold sans and a heavy wide italic for keywords; TikTok Sans Bold / Black (OFL,
already in `default/fonts/`) are the closest faces on disk. Swap `font_file` / `accent_file` if the exact fonts are
supplied.
